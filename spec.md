# spec — signup-landing

## Что это

Одна статическая страница с формой заявки на демо-урок: имя + email. Своего бэкенда нет —
заявка уходит на внешний сервис приёма форм.

## Что значит «готово»

Три проверяемых условия, все три обязательны:

1. Страница собирается: `npm run build` завершается без ошибок.
2. Форма не отправляет пустые и неверные поля — и говорит человеку, что именно не так.
3. Тесты зелёные: `npx playwright test`.

«Выглядит нормально» в этот список не входит намеренно: это не проверяемо.

## Границы

- Бэкенда не пишем. Приём заявок — внешний сервис, его endpoint подставляется перед деплоем
  и в репозиторий не коммитится.
- Аналитики, A/B, многошаговых форм — нет. Два поля.
- Фреймворка нет. Vite + обычный HTML/CSS/JS.
